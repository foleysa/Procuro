# Pulse — Procuro data product (desk-aligned)

**LoE:** Procuro SaaS only. Not FSA. Not the Weekly Brief.

Pulse is the recurring **judgment-grade brief + signal feed** on the same
horizontal spine as the desk: procurement, supply chain, and logistics.
Industry verticals are **edition lenses**, not a niche identity.

| Surface | What it is |
|---|---|
| **Pulse Core** | Horizontal Observe + Orient questions + suggested Decide. Logistics lens included. |
| **Edition skins** | Day 0–30: Industrial MRO (`mro`) and Food & Ag (`food`). Same issue, chapter language. |
| **Layer C** | Labeled Decide / Learn events tagged by vertical + lever. The moat — not scrapers. |
| **Diligence Pack** | Point-in-time cut using the same section IDs + an edition appendix. |

Code: `@workspace/pulse`. Desk cycles stay in `@workspace/db` /
`runAnalysisCycle`. This package does **not** rewrite OODA.
